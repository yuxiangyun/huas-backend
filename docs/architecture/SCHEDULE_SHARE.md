# 课表分享合同

分享者须已登录。首页“第 x 周”标题右侧的金色转发图标分享当前选中的一周；点击确认后才创建分享快照，同次原生转发等待创建并核对成功的异步结果。确认前取消、切周和普通课表读取不创建快照；创建超时或失败不得转发无效课表链接。首页右上角菜单继续分享通用小程序卡片，原有刷新入口不变。卡片沿用现有封面，标题优先为“姓名的第 x 周课表”；学校未提供可靠教学周次时，用选中周的日期范围，例如“姓名的 10/5–10/11 课表”。姓名取学校登录资料。

每张个人课表卡片对应创建时的固定课表快照，仅包含学校课程，不包含本机自定义课程。后续调课、分享者刷新或收件人重复打开均不改写旧卡片。真实无课可以分享；课表未公布、日期不在教学周历内或获取失败不能分享个人课表；当前显示可用的降级旧课表时允许分享该内容。异步创建未及时完成时只可回退到明确标注未就绪的通用卡片，不得附带无效课表凭证。

持有有效分享凭证者无需登录，可在独立分享页看到“姓名第 x 周课表”标题（无周次时显示日期范围）、当前周课表网格与课程详情；不显示数据更新时间或分享创建时间。分享页右侧使用首页白色立体按钮“前往我的课程”，不提供切周、刷新、公告或校园圈。无论收件人是否已登录，打开卡片先显示分享页；分享者打开自己的卡片也一样。已登录者点击“前往我的课程”进入本人首页，未登录者进入现有登录页，登录成功后进入本人首页。

分享凭证与登录 JWT 分开。匿名读取仅凭分享凭证获得对应快照，不能读取分享者的其他学校数据或触发以分享者身份回源。凭证不包含学号、学校凭据或 JWT。卡片可继续转发，长期有效，不设自动过期，也不提供撤销；误发后依然可长期查看是已确认的产品规则。
