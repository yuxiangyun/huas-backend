# 01：学校故障不误触发整体退出，验证码到期立即失效

**What to build:** 用户遇到 CAS 服务故障时保留本服务登录态；只有真实交互要求触发整体退出。验证码严格按有效期消费。先修现有入口的错误路径，为后续迁移固定外部契约。

**Blocked by:** 无，可先实施。

**Status:** completed

## Acceptance criteria

- [x] CAS 普通 403/429、未知响应和缺 execution 不变成 3003/401；读取故障不计入用户密码失败。
- [x] 验证码读取时检查十分钟到期点并一次消费；周期清理只回收内存。
- [x] 明确保存凭据被拒绝或要求验证码仍保留交互标记和整体退出行为，且按开始 epoch 条件写入。
- [x] 统一使用支持 code/cause 链的现有传输分类器；CAS 登录 POST 不自动重放。
- [x] mobile 二次会话拒绝与版本竞争耗尽不冒充 CAS 凭据拒绝，修正所有现有外部错误映射。
- [x] 用生产类型检查和静态路径审查验证，记录尚无运行证据。

## 验证边界

只允许生产源码类型检查和静态审查。不新增、不读取、不修改、不运行测试，不使用临时复现脚本替代测试，不访问学校上游或生产数据。

## 实施证据

SchoolAccess.errors 统一传输分类及非交互故障；authentication 消费验证码时比较 expiresAt 并立即删除；CAS POST 通过 replayable=false 单次调用。 生产类型检查通过；仅有静态证据，未读写或运行测试。最终两轴审查见任务 08。
