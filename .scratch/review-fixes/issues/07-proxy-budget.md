# 07-proxy-budget

What to build: 修复独立部署 Nginx 模板读等待早于学校业务预算的问题。
Repository: server
Blocked by: none
Status: completed

证据边界：根 nginx.conf 读等待30秒，SchoolAccess请求预算45秒，课表Facade预算50秒；只有实际采用该模板或同样短超时的站点才会提前终止响应。本轮未读取线上配置，不断言线上已发生故障。

实现：模板proxy_read_timeout设为60秒，给50秒课表预算留10秒响应余量；连接与发送预算不变。部署文档说明Bun默认60秒，以及真实发布脚本仅写proxy_pass/maintenance，不同步模板。

架构复盘与精简：考虑过向活动include写入读超时，但脚本会在保留既有location其余指令的情况下替换proxy_pass，盲插可能与站点已有同名指令冲突，造成nginx校验失败。维持模板和站点配置所有权边界，只在模板修正已确认值，部署文档要求核对有效上下文；无需新环境变量、共享配置生成器或修改发布状态机。

实现者整体逻辑审查钩子：小程序校园卡55秒与课表75秒请求等待均覆盖对应应用45/50秒预算；代理60秒不会早于应用有界恢复和课表仲裁，Bun默认60秒不缩短应用预算。原始30秒仅影响代理等待，不改变应用缓存提交与共享恢复。连接/发送、路由、maintenance、槽位切换与学校操作重放均保持原行为。已扫描仓库其他代理生成入口，未发现另一份proxy_read_timeout设置；既有站点实际生效配置仍需由运维现场核对。L3、L2及根配置地图已同步。未运行测试、未访问线上、未推送或部署。

主agent整体逻辑与架构审查：通过。45/50秒应用预算、默认Bun60秒和代理60秒、小程序对应55/75秒等待衔接成立；连接/发送/重放/共享恢复未改变，既有站点不盲插重复指令。模板单值与部署契约保留了最小职责边界。主审纠正台账课表等待为实际75秒，并将临时核验状态从永久运维文档移回本台账；补改后重新审查通过。
